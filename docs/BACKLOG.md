# 개발 백로그

## P0: 해커톤 시연

- [x] 저장소와 실행 하네스를 구성한다.
- [x] Antigravity 프로젝트 규칙과 스킬을 구성한다.
- [x] 정책, Claim과 시나리오 계약을 정의한다.
- [x] 합성 fixture를 제공하는 API를 구성한다.
- [x] 완전성 경고가 표시되는 웹 골격을 구성한다.
- [x] 텍스트와 PDF 정책 입력을 구현한다.
- [x] HWPX 또는 HWP 입력 한 형식과 텍스트 대체 경로를 구현한다.
- [x] 규칙 추출 결과를 JSON Schema로 검증한다.
- [x] 현재 정책과 제안 정책의 차이 화면을 구현한다.
- [x] 수도권 시군구 경계와 지도 시각화를 연결한다.
- [x] 인과 그래프 시각화를 연결한다.
- [x] 가구 유형별 JEV 어댑터를 구현한다.
- [x] 지도와 페르소나를 같은 화면과 `scenario_id`로 연결한다.
- [x] 발표용 정책 원문, 추출 결과와 시뮬레이션을 오프라인 캐시한다.
- [x] 설명 및 인과 경로에 근거 ID 인용을 강제한다.
- [ ] 실제 정책 원문 한 건을 실시간 Gemini API로 구조화한다(현재 오프라인 검증 스냅샷 캐시 및 추출 어댑터 연동).
- [ ] Cloud Run에 웹과 API를 배포한다.
- [ ] 3분 데모 영상과 영문 제출문을 완성한다.

## P1: 정책 원장

- [ ] 필수 공식 출처 목록을 확정한다.
- [ ] 국가법령정보센터와 부처 보도자료 수집기를 구현한다.
- [x] 정책 패키지를 원자 규칙으로 분해한다.
- [x] 발표, 공포, 시행, 유예와 종료일을 정규화한다.
- [ ] 행정구역과 지정구역의 유효기간을 관리한다.
- [x] 규칙 변경, 대체, 예외와 충돌을 탐지한다.
- [x] 정책 스냅샷 완전성 감사 기능을 구현한다.

## P2: 근거 그래프

- [x] KDI와 한국은행의 핵심 자료를 Markdown 근거 카드로 정리한다.
- [x] KDI와 한국은행 연구를 Claim으로 구조화한다.
- [x] 효과값, 시차, 표본, 방법과 한계를 연결한다.
- [x] 상반된 연구를 조건별로 비교한다.
- [ ] 금융사 보고서를 시장 국면과 작동 경로에 연결한다.

## P3: 시뮬레이션

- [ ] LTV, DTI, DSR 구매 가능액 계산기를 구현한다.
- [ ] 취득, 보유와 양도 비용 계산기를 구현한다.
- [x] JEV 가구 상태와 행동 계약을 확정한다.
- [ ] 지역 패널 기준 모형을 구현한다.
- [ ] 시간 반응과 공간 전이 모형을 구현한다.
- [ ] 예측 구간과 신뢰도 보정을 구현한다.
- [ ] 과거 정책 백테스트를 자동화한다.

## 작업 선택 원칙

1. 시연의 핵심 경로를 막는 작업을 먼저 처리한다.
2. 합성 숫자를 정교하게 만드는 작업보다 정책과 근거의 추적성을 우선한다.
3. 실제 데이터가 없으면 계약과 교체 지점을 구현하고 한계를 표시한다.
4. 완료한 작업은 테스트와 시연 경로에서 확인할 수 있어야 한다.
