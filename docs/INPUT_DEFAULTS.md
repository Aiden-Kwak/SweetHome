# 지역 선택과 공급 조건의 기본 입력값

정책 적용 지역은 전체 선택, 서울 25개 구 추가 선택, 시도별 선택과 모두 해제를 지원한다. 서울, 인천, 경기 목록을 구분하고 내부 고정 높이를 없애 체크박스 행이 잘리지 않도록 한다. 일괄 선택은 법적 적용 지역을 자동 판정하는 기능이 아니다.

공급 조건을 처음 열거나 지역을 추가하면 다음 비교용 시작값을 자동 입력한다.

| 항목 | 시작값 |
| --- | --- |
| 기준 시나리오 주택 수 | 100,000호 |
| 검토 사업 수 | 10개 |
| 사업당 세대수 | 세대수 기준 변경은 400세대, 연면적 비율 변경은 250세대 |
| 주거 연면적 비율 | 세대수 기준 변경은 85%, 연면적 비율 변경은 95% |
| 비교 기간 | 12개월 |
| 기간 내 공급 전환 비율 | 0.25 |
| 공급 1% 변화당 가격 반응 계수 | 0.5 |

이 값은 지역별 관측 통계나 추정 계수가 아닌 시나리오 시작값이다. 기존 계약의 `input_basis: illustrative`로 전달하며 출처 URL은 추측하지 않는다. 사용자가 수정한 지역의 값은 다른 지역을 추가해도 유지한다. '기본 시나리오 값으로 복원'을 누르면 선택한 지역의 값을 초기화한다. 적용 조건 확인은 자동으로 체크하지 않으며, 값이나 지역이 바뀌면 확인을 다시 받아야 한다.
