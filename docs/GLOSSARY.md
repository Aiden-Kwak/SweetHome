# 용어 사전과 빠른 도움말

정책 비교 본문, 가구 설명, 지역별 작동 경로, 연구 상세와 그래프의 선택 노드 설명에서 용어 옆에 정보 아이콘을 표시한다. 버튼이나 체크박스 라벨 안에 다른 버튼을 중첩하지 않고, 정책 제목의 도움말은 선택 컨트롤 옆에 배치한다.

정보 아이콘에 마우스를 올리거나 키보드로 포커스하면 설명을 표시한다. 터치로도 열 수 있으며, Escape, 바깥 영역 클릭 또는 포커스 이동으로 닫는다. 설명으로 마우스를 옮겨도 읽을 수 있도록 잠시 닫힘을 지연한다. 팝업은 화면 바깥이나 패널 경계에 잘리지 않도록 별도 레이어에서 표시한다.

상단 `용어 사전`에서 전체 목록을 검색하고 공식 참고 자료를 열 수 있다. 사전은 `apps/web/src/glossary-data.ts`에 있으며 서브 에이전트가 공식 자료를 확인하여 작성했다. 설명은 개념 안내이며 현행 규제 비율, 상품별 적용 조건이나 투자 조언을 제공하지 않는다. 시뮬레이션 입력과 그래프 원장을 바꾸지 않는다.

용어 자동 매칭은 긴 이름을 먼저 처리한다. 따라서 `스트레스 DSR`과 일반 `DSR`을 구별하며 같은 문단에서 반복되는 용어는 한 번만 설명한다. 입력 폼, 코드, 식별자와 원본 데이터 자체에는 아이콘을 삽입하지 않는다.

## 검증

`make check`로 용어 매칭과 기존 기능의 회귀 검사를 실행한다. 브라우저에서는 호버, 키보드, Escape, 출처 링크, 사전 검색, 모바일 터치와 화면 경계에서의 팝업 위치를 확인한다.
