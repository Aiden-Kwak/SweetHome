# 정책효과 근거 자료실

이 폴더는 PolicyMap에서 정책효과의 방향, 크기, 시차와 적용 조건을 판단할 때 참고할 연구를 Markdown 근거 카드로 정리한 자료실이다. 원문 전체를 복제하지 않고, 시뮬레이션과 지식 그래프에 필요한 메타데이터와 조건부 주장만 정리한다.

## 사용 원칙

- 연구 결과 하나를 보편적인 정책효과로 간주하지 않는다.
- 효과값은 정책, 지역, 표본 기간, 결과 변수, 분석 기간과 시장 국면이 일치할 때만 정량 모형의 후보 계수로 사용한다.
- 상반된 결과는 평균으로 합치지 않고 별도 `Claim`으로 보존한다.
- 원문 표와 산식의 위치를 확인하지 못한 수치는 정량 모형에 넣지 않는다.
- 기관의 공식 연구와 저자의 분석 결과를 해당 기관의 공식 정책 입장으로 혼동하지 않는다.
- 근거 등급은 출판기관의 권위가 아니라 연구 설계와 현재 사용 목적의 적합성을 평가한다.

## 잠정 근거 등급

| 등급 | 사용 기준 |
| --- | --- |
| A | 인과 식별이 강하고 정책, 지역, 결과 변수와 분석 기간이 현재 시나리오에 직접 대응한다. 원문 표와 강건성 검정을 확인했다. |
| B | 사건연구, 패널분석, 준실험 또는 미시자료 분석으로 효과를 추정했지만 외적 타당성이나 식별에 제한이 있다. |
| C | 구조모형, VAR, 옵션가치 모형, 상관 분석 또는 가정 의존도가 높은 시뮬레이션 결과이다. |
| D | 해설, 칼럼, 언론 요약 또는 합성 자료이다. 방향과 맥락을 확인하는 보조 자료로만 사용한다. |

현재 등급은 공개 요약과 확인 가능한 원문 내용을 바탕으로 매긴 잠정값이다. 원문 표, 부록과 강건성 검정을 검토하면 등급이 바뀔 수 있다.

## 현재 확인된 충돌과 보완 관계

### 금융규제의 단기효과와 장기효과

한국은행 2016년 연구는 DTI 규제가 표본 기간의 주택가격을 정책 의도에 맞게 움직였다고 분석했다. KDI 2022년 구조모형은 LTV 강화가 장기적으로 주택가격을 낮추지 못할 수 있다고 분석했다. 두 결과는 분석 기간과 방법이 다르므로 하나가 다른 하나를 바로 반박한다고 볼 수 없다.

PolicyMap에서는 다음처럼 분리해야 한다.

- 단기 반응 Claim: 거래량, 대출, 주택가격의 1개월에서 24개월 반응을 저장한다.
- 장기 균형 Claim: 자산배분, 저축, 공급과 상대가격의 장기 변화를 저장한다.
- 두 Claim을 합성할 때에는 시간 가중치와 시장 국면 규칙을 명시한다.

### 선별 규제의 직접효과와 전이효과

KDI 2023년 연구는 토지거래허가구역 안에서는 가격과 거래량이 감소했지만 가까운 비규제지역의 가격은 상승했다고 분석했다. 따라서 지역 규제는 대상 지역의 직접효과와 인접 지역의 전이효과를 반드시 별도로 계산해야 한다.

### 금융규제와 통화정책

한국은행 2025년 자료들은 대출규제만으로 결과를 설명하기 어렵고, 금리 수준과 규제 시행 순서가 정책효과를 바꿀 수 있다고 본다. 시뮬레이션 입력에는 정책 변경뿐 아니라 기준금리와 유동성 국면도 포함해야 한다.

## Claim 전환 전 확인사항

1. 원문 표와 부록에서 추정치, 표준오차와 신뢰구간을 확인한다.
2. 처리집단과 비교집단의 정의를 기록한다.
3. 표본 시작일과 종료일을 ISO 8601 형식으로 기록한다.
4. 결과 변수가 수준, 로그, 증가율 또는 지수 중 무엇인지 확인한다.
5. 효과값이 퍼센트인지 퍼센트포인트인지 구분한다.
6. 누적효과인지 특정 시점의 효과인지 확인한다.
7. 정책 발표일, 시행일과 시장 선반영 기간을 구분한다.
8. 원문 위치를 페이지, 표, 그림 또는 장과 절 단위로 기록한다.

## 남은 작업

- 각 보고서 PDF의 표와 부록을 기준으로 수치 검증을 완료해야 한다.
- 검증된 Claim을 `data/evidence/claims.json`으로 내보내는 변환 절차가 필요하다.
- 증권사와 금융사 보고서는 공개 URL과 재배포 조건을 확인한 뒤 보조 근거 카드로 추가해야 한다.
- 같은 정책을 다룬 국내외 학술논문을 추가하여 기관별 관점 편향을 줄여야 한다.
