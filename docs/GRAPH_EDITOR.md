# 지식 그래프 노코드 편집기

## 사용 방법

상단의 `지식 그래프` 탭에서 API가 제공하는 정책, 지역, 가구, 작동 경로와 연구 근거를 탐색한다. 기본 화면은 선택한 지역의 직접 연결만 표시한다. 전체 그래프는 별도 버튼으로 전환하며 확대와 축소, 스크롤을 지원한다.

1. 왼쪽에서 이름 또는 ID를 검색하고 유형을 필터링한다.
2. 노드를 선택하고 오른쪽 폼에서 이름, 유형, 검토 메모와 출처를 수정한다.
3. `노드 변경 저장`으로 편집본에 반영한다. 정책 규칙 수정에는 URL과 원문 위치 또는 발췌문이 필요하다.
4. `관계 추가`에서 시작 노드, 관계 유형과 도착 노드를 선택한다. 연결선이나 연결 목록을 선택하면 기존 관계를 수정할 수 있다.
5. 삭제 시 확인을 거치며, 노드를 삭제하면 해당 노드의 관계도 함께 삭제한다. 같은 탭 세션에서 최근 30회까지 실행 취소할 수 있다.
6. `내보내기`로 JSON 편집본을 보관하고 `가져오기`로 같은 기준일과 지역의 편집본을 복원한다. 파일 교체와 원본 복원도 실행 취소할 수 있다.

## 저장과 신뢰 범위

- API 원본을 수정하지 않는 클라이언트 편집본이다. 저장 위치는 브라우저 localStorage이며 기준일과 지역별로 분리한다.
- 새로고침 후 편집본을 복원한다. 브라우저 데이터 삭제, 다른 브라우저 또는 다른 포트에서는 공유되지 않는다.
- 서버 원장 반영, 공동 편집, 인증, 승인과 시뮬레이션 재계산은 구현하지 않았다. 여러 탭에서 동시에 편집하는 작업은 지원하지 않는다.
- 편집한 노드와 관계에는 `editor_status: unverified`를 남긴다. 노드의 상태도 `unverified`로 변경한다. 연구 간 상충 관계를 자동 병합하지 않는다.
- 원본 속성은 보존하고, 편집 메모와 검토용 URL은 `editor_note`, `editor_source_url`, `editor_source_locator`에 저장한다. 공식 출처 여부를 자동 검증하지 않는다.
- API의 정책 또는 연구 원문은 별도의 읽기 전용 출처로 보여준다. 수정한 검토용 URL이 원본 출처를 덮어쓰지 않는다.
- 노드 유형 변경과 관계 추가는 검토 가설이며 온톨로지의 도메인 제약이나 법적 타당성을 검증한 결과가 아니다.
- 폼에 입력했지만 저장 버튼을 누르지 않은 변경은 노드를 전환하면 사라진다.

## 구현 계약

서버 계약은 변경하지 않았다. `/api/v1/graph`는 기준일과 지역을 응답하지 않으므로 웹의 `fetchGraph`가 요청에 사용한 `as_of`, `region_code`를 응답 객체에 추가한다. 기존 TypeScript 타입과 실제 서버 응답 사이의 불일치를 이 어댑터에서 처리한다.

웹 전용 `GraphDraft` v1은 기준일, 지역, 원본 상태, 노드와 안정적인 편집용 ID를 가진 관계를 저장한다. 가져올 때 형식, ID 중복, 존재하지 않는 노드 참조, 자기 연결, 유형과 크기를 검사한다. 최대 2MB, 노드 500개와 관계 2,000개를 지원한다.

SVG 연결선과 HTML 버튼을 조합하여 키보드 접근성과 폼 편집을 제공한다. 외부 그래프 라이브러리나 클라우드 저장소 의존성은 추가하지 않았다. 도메인 편집 연산과 검증, 레이아웃은 `graph-editor.ts`, 화면은 `KnowledgeGraph.tsx`에 분리했다.

## 검증

`make check`와 브라우저 검증을 사용한다. 노드와 관계의 생성, 수정, 삭제, 실행 취소, 새로고침 복원, 파일 가져오기, 안전한 출처 링크, 잘못된 연결과 반응형 화면을 확인한다.
