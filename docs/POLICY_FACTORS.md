# 주요 규제와 허가 조건 표

메인 시뮬레이션 화면의 시나리오 설명 아래에 `PolicyFactors`를 배치한다. 기존 API 응답의 정책 스냅샷과 가구 값을 표시하며 API 계약이나 계산 모형을 변경하지 않는다.

- 선택 가구의 대출 비교 금액을 규제상 대출 한도와 별도 행으로 표시한다. 기존 합성 가구 값은 정책 선택에 따라 재계산되는 것으로 표현하지 않는다.
- LTV와 DSR은 대출 규칙의 기존 요약에 있는 기준 문구를 그대로 보여준다. 별도의 변경 비율을 추측하지 않는다.
- 대출 한도, 스트레스 DSR, 토지거래허가와 실거주, 처분 기한, 정책대출 예외 등 등록된 규칙을 변경 전후로 비교한다.
- 규칙의 선택 여부, 대상 지역 목록 포함 여부, 시행일과 근거를 표시한다. 지역 목록 포함은 필지 또는 가구별 법적 적용 판정이 아니다.
- 가구 선택은 기존 가구 패널과 공유한다. 지도에서 지역을 바꾸면 표의 지역 목록 포함 표시도 갱신된다.
- 표는 스냅샷 기준일을 표시한다. 과거 시나리오를 현재 시행 중인 정책으로 표시하지 않는다.
- 모바일에서는 표 영역 안에서만 가로로 스크롤하며, 용어 도움말과 근거 펼치기를 키보드로 사용할 수 있다.
