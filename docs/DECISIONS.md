# 의사결정 기록

## ADR-009: 실제 문서 처리와 단일 규칙 실험을 fixture에서 분리한다

- 상태: 채택
- 날짜: 2026-10-16

ADR-007의 임시 메모 전용 화면을 실제 분석 API로 연결한다. pypdf를 추가하여 PDF 텍스트를 읽고 HWPX는 표준 라이브러리로 처리한다. Gemini 설정이 없으면 제한된 규칙 기반 추출임을 명시하며, 기존 fixture 추출 API는 실제 문서 입력을 거절한다. 새 후보는 전체 정책 원장으로 승인하지 않는다.

검토한 하나의 규칙과 명시적 가구, 지역, 시간 입력으로 조건부 실험을 계산한다. 가격 민감도는 사용자가 계수를 입력한 매매 금융 규칙에만 표시하며 지역별 효과를 임의로 다르게 만들지 않는다. UI에는 실제 예측이 아니라는 상태와 계산식을 표시한다.

## ADR-008: 지식 그래프 편집은 검토용 초안으로 분리한다

- 상태: 채택
- 날짜: 2026-10-16

원장 승인이나 효과 모형이 연결되지 않은 상태에서 그래프 편집이 가격을 바꾸는 것처럼 표시하지 않는다. API 그래프의 사본을 브라우저에 저장하고 파일로 내보낼 수 있게 한다. 기존 출처 속성을 보존하고 수정 항목은 미검증으로 표시한다. SVG와 HTML을 사용하여 별도 의존성 없이 탐색과 폼 기반 편집을 제공한다. 범위와 저장 계약은 [지식 그래프 편집기](GRAPH_EDITOR.md)에 기록한다.

## ADR-001: 정책 원장을 제품의 기준으로 사용한다

- 상태: 채택
- 날짜: 2026-10-15

일부 대표 정책만 사용하는 경우 누락 변수로 인해 결과를 신뢰하기 어렵다. 따라서 기능 범위는 단계적으로 구현하더라도 신뢰 가능한 결과를 표시하려면 대상 날짜와 지역의 정책 스냅샷이 완전해야 한다.

## ADR-002: 연구 결과를 Claim 노드로 저장한다

- 상태: 채택
- 날짜: 2026-10-15

같은 정책도 연구 기간, 지역, 방법과 시장 국면에 따라 결과가 다르다. 연구 결론을 하나의 사실로 합치지 않고 조건이 포함된 별도 Claim으로 저장한다.

## ADR-003: Antigravity skills를 사용한다

- 상태: 채택
- 날짜: 2026-10-15

레거시 workflows 형식 대신 `.agents/skills/<name>/SKILL.md`를 사용한다. 규칙은 `GEMINI.md`와 `.agents/rules/`에 둔다.

## ADR-004: 웹과 API를 분리한다

- 상태: 채택
- 날짜: 2026-10-15

웹은 설명과 시각화만 담당한다. 정책 적용 판정, 데이터 접근과 시나리오 실행은 API가 담당한다. 두 서비스는 Cloud Run에 독립적으로 배포할 수 있어야 한다.

## ADR-005: 현재 결과는 합성 fixture로 표시한다

- 상태: 채택
- 날짜: 2026-10-15

실제 정책 원장과 검증된 모형이 없으므로 현재 결과를 실제 예측으로 표시하지 않는다. 모든 응답과 화면에 `DEMO_INCOMPLETE`와 `SYNTHETIC_FIXTURE` 상태를 포함한다.

## ADR-006: 관측 자료와 합성 시뮬레이션을 분리한다

- 상태: 채택
- 날짜: 2026-10-16

서울시 공식 실거래 sample API와 통계청 2018 경계 스냅샷을 별도 `data/public` 폴더와 `/api/v1/public-context` 계약으로 제공한다. 원자료, 조회 시각, 출처, 수집 범위와 해시를 보존한다. 소규모 거래 표본으로 가격 추세나 정책 효과를 산출하지 않는다. SVG로 경계를 표시하므로 새로운 지도 의존성은 추가하지 않는다.

## ADR-007: 구현되지 않은 자동 분석을 완료 상태로 표시하지 않는다

- 상태: 채택
- 날짜: 2026-10-16

기존 추출 API는 입력에 관계없이 같은 합성 정책을 반환한다. 사용자 화면은 이를 실제 분석처럼 호출하지 않고 원문 입력 및 검토 준비 단계로 명확히 표시한다. 확인되지 않은 완전성 백분율과 캐시 검증 배지를 숨기고 실제 제공 범위와 미구현 항목을 설명한다.

## ADR-010: 새 정책의 유형에 맞는 지표와 공급 계산을 연결한다

- 상태: 채택
- 날짜: 2026-10-16

새 문서 분석 API와 조건부 계산 API에서는 입력에 근거한 규칙과 결과를 반환한다. 공급 규칙에 금융 카드를 붙이는 방식을 없애고, 사업 경로 대상 변화와 입력한 공급 시점 변화로 가격 민감도를 계산한다. 기준값 확대만으로 공급량 증가를 단정하지 않는다. 전세보증은 임차 예산, 연령은 기준 변화, 가격 계수가 없는 매매 금융 규칙은 구매 예산을 주요 지표로 쓴다.

반복적인 경고 문구는 원문, 계산식과 입력 범위를 확인하는 한 패널로 통합한다. 결과 근처에는 ‘입력 가정 기반 시나리오’와 예시 입력의 출발점을 유지한다. 검증 상태를 실제 전망 수준으로 높여 표시하지 않는다.
