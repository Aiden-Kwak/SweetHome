# 공개 관측 자료

이 폴더는 합성 정책 및 결과를 보관하는 `data/fixtures`와 분리되어 있습니다. 실제 공개 자료를 저장하지만 전체 시장을 대표하지 않습니다.

## 출처와 이용 조건

- 경계: [통계청 SGIS 자료를 변환한 southkorea-maps 2018 데이터](https://github.com/southkorea/southkorea-maps/tree/master/kostat/2018/json)입니다. 해당 배포처의 LICENSE.md는 공공누리 제1유형을 명시합니다. 수도권 77개 시군구 경계를 단순화된 TopoJSON에서 해석했습니다. 11개 시나리오 지역만 법정동 시군구 코드와 명시적으로 대응했습니다. 이 경계를 현재 행정구역이나 규제구역의 법적 경계로 사용하지 않습니다.
- 거래: [서울특별시 부동산 실거래가 정보](https://data.seoul.go.kr/dataList/OA-21275/S/1/datasetView.do)입니다. 서울시가 국토교통부 자료를 연계하며 공공누리 제1유형으로 제공합니다. 공식 sample API가 반환한 강남구, 성동구, 마포구의 2025년 6월 26일과 27일 아파트 계약을 보관합니다.
- 거래당 금액은 원본 `THING_AMT`의 만원 단위를 원 단위로 변환했습니다. 전용면적, 층, 계약일, 취소일은 원본 값을 유지합니다.

각 지역과 날짜에 대해 첫 5건씩 총 30건을 조회했습니다. 취소 신고도 원자료에 보존하며 화면에서는 기본 제외합니다. 첫 5건은 무작위 표본이 아닙니다. 지역별 시세, 가격 추세, 정책 효과를 계산하지 않습니다. 조회 시점의 정정과 취소가 포함되므로 2025년 당시 이용 가능했던 데이터셋으로 취급하지 않습니다.

## 파일과 갱신

`context.json`은 API가 검증 후 제공하는 정규화된 스냅샷입니다. `raw/`에는 공식 응답과 지도 원자료를 보관합니다. 원본 URL, 조회 시각, SHA-256, 응답 전체 건수와 실제 수집 건수는 `context.json`에 포함됩니다.

```bash
node scripts/refresh-public-data.mjs
make check
```

수집에는 별도의 키가 필요하지 않습니다. API 호출은 공개 sample 한도를 따릅니다. 운영용 전체 수집은 정식 인증키, 페이지네이션, 정정 및 취소 반영, 시점별 이력 관리가 필요합니다. 위 명령은 고정된 지역과 계약일의 표본을 다시 수집하며 실시간 전체 시장 수집 명령이 아닙니다.

새 자료는 `/api/v1/public-context`로 제공하며 시뮬레이션 계수에는 전달하지 않습니다. 화면의 합성 결과를 실제 자료 기반의 검증된 예측으로 바꾸지 않습니다.
